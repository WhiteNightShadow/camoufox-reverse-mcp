## 版本说明

本补丁版本修复 Windows 上启用引擎层属性追踪后持续返回
`engine_trace_not_available` 的问题，对应
[Issue #11](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/issues/11)。

Camoufox 会把完整指纹配置按平台限制拆到 `CAMOU_CONFIG_1..n`。此前 MCP
对每个分块单独解析 JSON；多块配置解析失败后，又在保留旧分块的同时写入单一
`CAMOU_CONFIG`。浏览器会优先拼接旧分块，因此始终看不到新加入的
`propertyTrace`，追踪器也不会初始化。

## 修复内容

- 按底层 `MaskConfig` 的读取顺序完整重组连续分块，再解析和合并配置。
- 保留所有原始浏览器指纹字段，仅覆盖需要更新的顶层追踪配置。
- 使用 Windows 2047 字符、其他平台 32767 字符的限制重新生成任意数量的连续分块。
- 清理旧的单变量和尾部分块，避免旧配置继续遮蔽新配置。
- JSON 使用 ASCII 转义后再分块，避免 Unicode 内容落在 UTF-8 字节边界中间。
- 分块损坏且不存在有效单变量回退时直接报错，不以丢失指纹配置为代价继续启动。

## 兼容性

- `launch_browser(enable_trace=True)` 的接口和返回格式保持不变。
- 非追踪启动路径完全不受影响。
- 修复同样覆盖其他平台上超过 32767 字符的极大配置。
- 针对本问题，已安装支持属性追踪的 `camoufox-reverse` 用户只需升级 MCP；底层 `MaskConfig` 与 `PropertyTracer` 无需修改，不需要重新编译或替换浏览器。

## 验证

- 新增 13 个配置分块回归用例，包括调用真实 `camoufox.utils.get_env_vars()` 模拟 Windows 分块。
- Python 3.12 本地完整测试：`99 passed`。
- 额外使用 70KB 原始指纹配置模拟 Windows 2047 字符分块，验证全部字段和 `propertyTrace` 均可由底层格式重新解析。
