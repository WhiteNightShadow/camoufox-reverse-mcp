## 版本说明

这一版合并 [@Moojing-jianchuan](https://github.com/Moojing-jianchuan) 的 [#27](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/pull/27)，新增 `rdp_debugger(action=...)`，通过 Firefox 原生远程调试协议（`-start-debugger-server`）补齐 Playwright/Juggler 侧无法提供的真断点、单步、调用栈、作用域读取、暂停帧求值与请求前断点能力，并补齐多平台启动、并发取消、Unix socket 生命周期与孤立代理字符编码防护。

## 主要变更

- **断点与单步（`rdp_debugger` 20 个 `action`）**：支持 `launch`、`attach`、`enable`、`sources`、`source`、`breakable_lines`、`breakable_positions`、`set_breakpoint`、`remove_breakpoint`、`wait_paused`、`frames`、`scopes`、`evaluate`、`step`、`resume`、`interrupt`、`reload`、`xhr_breakpoint`、`status`、`close`；支持按 `source_url` 跨导航重挂断点、按 `source`（`sourceId`）断无 URL 脚本，外部 `column` 按 1-based 传入并自动吸附到同行最近 0-based 可停位置，`xhr_breakpoint` 在 `fetch` / XHR 发出前暂停。
- **暂停现场与长字符串安全读取**：暂停后可读完整调用栈（`frames`）、递归词法作用域绑定（`scopes`）并在指定栈帧求值（`evaluate(frame_actor=...)`）；`source` 与 `evaluate` 读取 `longString` 按 UTF-16 码元分片，跨边界代理对只重拉 2 个码元精准拼接，源码或求值结果内嵌孤立代理项自动清洗为 `U+FFFD`，保证落盘和 stdio JSON 编码安全。
- **配置继承与传输隔离**：可执行文件通过 `camoufox.pkgman.launch_path()` 解析当前激活版本（支持软链接解析与 `browser_version` 选择，兼容 macOS `Camoufox.app` 与原版 Firefox 回退），继承 `CAMOU_CONFIG` 指纹、无认证代理、`--headless`、`--os`、`--locale`；探测与构造启动计划期间以线程安全引用计数禁止静默下载浏览器。默认监听随机空闲 loopback 端口；macOS / Linux 可传 `unix_socket=True` 使用 `0700` 临时目录内的 Unix socket（超长 `$TMPDIR` 自动回退 `/tmp`，`attach` 模式断开不误删外部 socket）。
- **异步并发取消与生命周期收尾**：阻塞 I/O 运行在 `asyncio.to_thread` 中且按会话加锁串行化；取消请求会同步打断启动轮询或 `wait_paused` 并在下次调用时恢复协议队列，不会向全局状态残留孤儿会话；`close()` 与主线程信号清理（`SIGINT`/`SIGTERM`/`SIGHUP` + `atexit`）先触发取消再收锁清理进程树与临时 profile。

## 兼容性

- 工具总数从 41 个扩充为 42 个（新增第 10 组「Firefox RDP 断点调试」），原有 41 个工具参数与返回结构保持不变。
- `rdp_debugger(action="launch")` 启动独立的浏览器进程与临时 profile，与 Playwright `launch_browser` 的会话、网络捕获及内存态 Cookie 互不共享。
- 断点暂停会拉大页面真实时钟间隔，且调试端口开启 `devtools.chrome.enabled`；建议仅在独立观察会话中用于定位算法、闭包状态或发包入参，收口验证回到无断点的干净会话或离线环境。

## 验证

- 本机测试套件：`630 passed, 3 skipped`（含 `CAMOUFOX_RDP_SMOKE=1` 真浏览器冒烟测试与文档契约检查）。
- 端到端实测：在 Windows（Camoufox 152 reverse.5）与 macOS（官方 Camoufox 158 `Camoufox.app`、原版 Firefox Nightly、`unix_socket=True`）上完整跑通 `--self-test`（`about:blank` 离线闭环）。
