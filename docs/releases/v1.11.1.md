## 版本说明

这一版修复 Windows CI 下两条 POSIX Unix socket 路径测试未跳过的问题，并对齐发布工作流的 Release Notes 结构校验，工具行为与默认配置不变。

## 主要变更

- **Windows 回归测试兼容**：`test_unix_socket_path_is_private` 与 `test_unix_socket_path_stays_within_af_unix_limit` 在 `os.name == "nt"` 或缺少 `AF_UNIX` 时跳过，并新增 `test_make_unix_socket_path_rejects_windows` 在全平台断言 Windows 显式拒绝 `unix_socket=True`。
- **CI 与发布说明校验对齐**：去重 `.github/workflows/ci.yml` 中重复执行的 `tests/test_debugger_rdp.py`，并对齐 `docs/releases/v1.11.0.md` 与 `v1.11.1.md` 的章节结构以通过自动发版流水线校验。

## 兼容性

- 与 `v1.11.0` 完全兼容，全部 42 个 MCP 工具名称、参数及返回结构不变。
