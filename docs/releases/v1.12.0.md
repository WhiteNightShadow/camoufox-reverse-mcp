## 版本说明

这一版合并 [@Moojing-jianchuan](https://github.com/Moojing-jianchuan) 的 [#28](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/pull/28)，解决「脚本每次请求重新构建、opcode 编号与列偏移随构建变化」场景下的三项痛点：新增源码级正则插桩 `instrumentation(inject=...)`、本地文件 Mock 替换 `intercept_request(mock_response={body_file})` 与跨刷新动态正则断点 `rdp_debugger(set_breakpoint, url_pattern=..., find=...)`，原有参数与默认行为保持不变。

## 主要变更

- **源码级正则插桩（`instrumentation(inject=[{find, before|after, group}])`）**：支持在同一脚本内按 `re.MULTILINE` 正则全部匹配位置插入语句并展开 `$1..$99`/`$0` 捕获组，命中与跳过计数同步写入返回值、`status` 与 `log`；内置四层语法保护——首尾 `;` 语句包裹（含 `}` 结尾表达式与 `;\n…\n;` 行注释保护）、字符串/嵌套 `${...}` 模板/注释/正则字面量逐处跳过、`switch` 的 `case`/`default` 标签跳过三元 `? :` 自动挪至冒号后（排除 `{default: ...}` 对象属性），以及 `esprima` + 本地随包 Acorn（覆盖现代 ES2025/ESM）重解析校验与逐组回退。
- **磁盘大文件响应 Mock（`intercept_request(mock_response={body_file})`）**：支持读取 ≤10 MiB 的常规 UTF-8 本地文件（相对路径按服务器工作目录解析，与内联 `body` 互斥），前置校验 `status`/`headers` 并在工作线程按请求实时重读，编辑离线改写脚本后刷新页面即可生效，`headers` 缺省时按后缀推断 `content-type`。
- **跨刷新动态正则断点（`rdp_debugger(action="set_breakpoint", url_pattern=..., find=..., occurrence=...)`）**：单遍扫描将正则匹配偏移按 UTF-16 码元换算为 `line/column` 并吸附到最近可停列，`reload` 与 `enable` 重建线程后自动重新 `sources()` → 重算偏移 → 重下（支持客户端取消时立即中断退出），新脚本未命中时记入 `reapply_failed`；`sources`、`source`、`breakable_*` 与 `remove_breakpoint` 同步支持 `url_pattern`。

## 兼容性

- 与 `v1.11.1` 完全兼容：42 个 MCP 工具名称不变，原有 `mode='ast'/'regex'`、`tap_stage_calls`、`filter_*`、`source`/`source_url` + `line`/`column` 及 `modify`/`block`/`log` 行为不变。
