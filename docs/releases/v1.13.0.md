## 版本说明

这一版合并 [@Moojing-jianchuan](https://github.com/Moojing-jianchuan) 的 [#29](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/pull/29) 与 [#30](https://github.com/WhiteNightShadow/camoufox-reverse-mcp/pull/30)，围绕「大体积动态载荷与敏感凭据不刷入对话上下文」及「浏览器/调试器异常断开与冷启动竞态自愈」补齐五项核心能力：新增第 43 个工具 `extract_script`，增强 `evaluate_js(output_file=...)`、`cookies(action="header")` 与 `wait_for(mode="request")`，并修复死会话卡死与 `rdp_debugger` 首标签页竞态。

## 主要变更

- **动态载荷脚本提取（`extract_script`）**：针对通过 `fetch` + `eval` 下发、无 `<script src>` 资源的动态 SDK，支持按点分或下标路径（如 `data.data`、`items[0].script`，空串代表整段响应即为脚本）从已捕获响应或文本中提取源码并安全落盘；默认拒绝被 `network_capture(max_body_size=...)` 截断的半截响应体（除非显式传 `allow_partial=True`），与 `instrumentation(action="rewrite_source")` 及 `intercept_request(mock_response={"body_file": ...})` 组成完整离线改写回灌链路。
- **JS 求值结果直接落盘（`evaluate_js(output_file, output_encoding, overwrite)`）**：在页面脚本求值前完成目标路径与编码预校验（拒绝符号链接、目录与非普通文件，`overwrite=False` 走 `O_CREAT|O_EXCL|O_NOFOLLOW`），严格要求 JS 返回值为字符串，自动清洗孤立 UTF-16 代理项并对 `base64` 开启严格解码校验，避免几百 KB 源码或字节码刷爆上下文窗口。
- **Cookie 请求头导出与已捕获请求收尾等待（`cookies(action="header")` / `wait_for(mode="request")`）**：`cookies(action="header", url, domain, output_file)` 默认按当前活跃 `http(s)` 页面 URL 遵循 RFC 6265 作用域、路径长度排序与过期筛选生成 `Cookie` 头，传入 `output_file` 时以 `0600` 权限落盘并将返回中的 `header` 置为 `None`；`wait_for(mode="auto"|"request"|"navigation", after_id)` 支持按 URL glob 与游标等待已捕获请求及其响应体完成收尾（非 `pending`）。
- **死浏览器句柄自愈与 RDP 首标签页轮询**：`BrowserManager` 统一使用 `_select_usable_page()` 在活跃标签页关闭时自动切至其余存活标签页，全部标签页关闭或连接断开时 `launch_browser` 自动清理旧路由与状态并重建会话（`recovered_stale_session=True`）；`rdp_debugger` 在 `enable()` 中接入支持取消信号的 `_wait_for_tabs()`（最多轮询 5s），消除冷启动瞬间报「没有标签页」的竞态。

## 兼容性

- 与 `v1.12.0` 完全向后兼容：原有 42 个工具名称与默认行为保持不变，新增第 43 个工具 `extract_script`，新增可选参数均具备向后兼容默认值且通过严格 JSON Schema 校验。
