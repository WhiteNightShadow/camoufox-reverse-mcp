# camoufox-reverse-mcp v1.3.0

本版本为 Camoufox 152 定制版提供可选、向后兼容的多版本启动能力，不改变任何
用户的默认/active 浏览器，也不会自动下载、覆盖或迁移缓存。

## 新增

- `launch_browser(browser_version=...)`：针对 Camoufox Python 0.5+，按
  `repo/build`、`repo/full-version` 或 `repo/exact-folder` 单次选择已安装浏览器。
- 选择器必须带 repo；同 repo 下存在相同 build 的多个资产时拒绝歧义并要求精确目录。
- active 与 selected 必须是相同完整 version/build；不一致时明确拒绝，避免生成错误 UA/指纹或读取错误共享资源。
- `check_environment()` 返回 Camoufox Python 版本、是否支持多版本、active、已安装 selector、能力标记和旧缓存迁移风险。
- `C.UTF-8` / `POSIX` 主机 locale 会安全回退到 `en-US`，不再把无效的 `C` 传给 Camoufox。

## 兼容性

- 不传 `browser_version` 时，启动路径与 v1.2.0 保持一致。
- Camoufox 0.4.x 继续使用原有平铺缓存；显式多版本选择会返回清晰错误，不会触发迁移。
- Camoufox 依赖范围为 `>=0.4.0,<0.6`，避免未来不兼容的大版本被静默安装。
- 代码从不调用 Camoufox 的 `set_active()` / `save_config()`。
- 官方 Camoufox 152 可使用普通 Hook、网络、脚本和插桩工具；只有
  `trace_property_access` 需要包含能力标记的定制版。

## 配套浏览器

[Camoufox Reverse 152.0.4 beta.30 reverse.2](https://github.com/WhiteNightShadow/camoufox-reverse/releases/tag/v152.0.4-beta.30-reverse.2)
基于官方 beta.30，PropertyTracer 仍使用既有 control/JSONL 协议，并作为 prerelease
与旧 Firefox 135 构建并存。

## 验证

- Python 3.10 / 3.12 × Camoufox 0.4.11 / 0.5.5 CI 矩阵。
- 默认、普通多版本和 trace 多版本启动 mock 回归。
- selector 歧义、`release/build/tag` 兼容、能力标记及 active 配置不变测试。
- macOS arm64 实包验证：官方 beta.30 普通启动、定制 beta.30 trace 开/关及旧版
  Firefox 135 trace 均通过；定制版 UA 为 Firefox 152，示例页实际记录 24 条、
  12 类属性访问，覆盖 Canvas、WebGL、AudioContext、Navigator、Screen 和 Window。
- 定制版使用 side-by-side 缓存安装与单次 selector 启动，验证前后 active 配置保持不变。
- 完整测试套件 131 项通过。
