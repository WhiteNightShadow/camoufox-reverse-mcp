# camoufox-reverse-mcp v1.4.1

This patch release pairs the existing MCP v1.4 tracing protocol with Camoufox
Reverse `v152.0.4-beta.30-reverse.5`.

The browser moves the existing `localStorage.getItem` and
`localStorage.setItem` native sites to Firefox 152's default LSNG `LSObject`
implementation. MCP behavior does not otherwise change:

- PropertyTracer remains protocol 1 and the reverse.5 build declares 77 native
  sites, including the separately reachable partitioned-storage get/set path.
- Event object/property names and `call` kinds are unchanged.
- Summary, timeline, sequence, filters, safe snapshots, private runs, native
  acknowledgements, and trace-off defaults are unchanged.
- The optional native `site` values for those two events now end in
  `dom/localstorage/LSObject.cpp`; persisted exact-site filters should update.
- Existing Firefox 135, reverse.3, and reverse.4 installations remain readable
  and selectable side by side.

Use the exact selector returned by `check_environment()`, normally:

```text
whitenightshadow/152.0.4-beta.30-reverse.5
```
