## 版本说明

对齐 Camoufox Reverse reverse.5，将 Firefox 152 的 `localStorage` 原生追踪迁移到实际 LSNG 路径，并正确表达历史 Trace 的覆盖信息。

## 主要变更

- reverse.5 声明 77 个原生注入点，覆盖 `LSObject` 和可达的 `PartitionedLocalStorage` get/set 路径。
- protocol 1、事件 object/property/kind 和现有聚合接口保持兼容。
- 历史 JSONL 没有浏览器能力标记，现改为返回 `hook_count=null`、`hook_count_known=false`。
- 精确 `site` 过滤条件应更新为新的 `LSObject.cpp` 路径。

## 兼容性

- Firefox 135、reverse.3、reverse.4 和 reverse.5 均可继续并存选择。
- 推荐使用 `check_environment()` 返回的精确 selector：`whitenightshadow/152.0.4-beta.30-reverse.5`。

## 验证

- 本地完整测试为 `147 passed, 1 skipped`。
- Python 3.10/3.12 × Camoufox legacy/current 四个 CI 组合全部通过。
- macOS arm64 与 Linux 实包完成 LSObject、分区存储和 MCP 汇总验证。
