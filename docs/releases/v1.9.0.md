## 版本说明

支持用 `uvx` 按标签固定版本安装和启动，不需要克隆仓库；已有的 `pip install -e .` 和 `python -m camoufox_reverse_mcp` 配置不需要改动。

## 主要变更

- 支持 `uvx --from "git+https://github.com/WhiteNightShadow/camoufox-reverse-mcp.git@v1.9.0" camoufox-reverse-mcp` 启动，新增 `--version`。README 补充固定版本、更新、预热和浏览器下载说明，也保留 `uv tool install` 的用法。
- 服务运行时，第三方库写到 `stdout` 的文本改走 `stderr`。缺少浏览器时的自动下载提示不再混进 MCP 协议流，协议字节本身不变。
- Playwright 启动补丁改为写临时文件后原子替换。uv 用硬链接安装时，不再改到全局缓存里其他环境共用的文件。
- `check_environment` 在没有可用浏览器时给出 `camoufox fetch` 命令。CI 增加 Camoufox 0.5.9 与 Playwright 1.62.0 组合，并在三个平台用 `uvx` 走真实协议握手。

## 兼容性

- 依赖范围不变，工具名、参数和默认行为不变，39 个工具的定义与 v1.8.0 逐字节一致。
- 本版没有发布到 PyPI，`uvx` 通过 Git 标签安装，本机需要 git。首次运行要下载依赖，建议先在终端执行一次 `--version` 和 `camoufox fetch`，再写入客户端配置。
- 第三方库的提示文本现在出现在 `stderr`。服务启动前的 `--version` 和 `--help` 仍输出到 `stdout`。
